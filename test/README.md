# FadeStreetPlugin — unit test projects

Generated by `generate_test_projects.js` in the GBStudio Plugin Patch Builder. Each folder is
a GB Studio project that installs this plugin in one configuration and exists to prove that
configuration still compiles. Build them all with `build_examples.js --tests`.

Every project carries one scene of each scene type, because GB Studio only compiles the state
file for a scene type the project uses.

| Project | What it covers |
|---|---|
| `DEFAULT` | FadeStreetPlugin on its own, every engine setting at its default. |
| `ALT_Cont_M_Sce` | FadeStreetPlugin with ContinuousScenePlugin, MetaTilePlugin, SceneStackExPlugin — selects engineAlt/Cont_M_Sce. |
| `ALT_ScreenS_M_Sce` | FadeStreetPlugin with ScreenScrollPlugin, MetaTilePlugin, SceneStackExPlugin — selects engineAlt/ScreenS_M_Sce. |
| `ALT_Cont_M` | FadeStreetPlugin with ContinuousScenePlugin, MetaTilePlugin — selects engineAlt/Cont_M. |
| `ALT_Cont_Sce` | FadeStreetPlugin with ContinuousScenePlugin, SceneStackExPlugin — selects engineAlt/Cont_Sce. |
| `ALT_M_Sce` | FadeStreetPlugin with MetaTilePlugin, SceneStackExPlugin — selects engineAlt/M_Sce. |
| `ALT_ScreenS_M` | FadeStreetPlugin with ScreenScrollPlugin, MetaTilePlugin — selects engineAlt/ScreenS_M. |
| `ALT_ScreenS_Sce` | FadeStreetPlugin with ScreenScrollPlugin, SceneStackExPlugin — selects engineAlt/ScreenS_Sce. |
| `ALT_Cont` | FadeStreetPlugin with ContinuousScenePlugin — selects engineAlt/Cont. |
| `ALT_M` | FadeStreetPlugin with MetaTilePlugin — selects engineAlt/M. |
| `ALT_Sce` | FadeStreetPlugin with SceneStackExPlugin — selects engineAlt/Sce. |
| `ALT_ScreenS` | FadeStreetPlugin with ScreenScrollPlugin — selects engineAlt/ScreenS. |
